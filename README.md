# Apple-Stock-Price-Prediction-Project
Apple Stock Price Prediction using Machine Learning | Developed during a Data Science Internship at AI Variant

## Project Objective
The objective of this project is to develop a reliable forecasting model for predicting future Apple stock prices using historical market data. By applying time series forecasting and machine learning techniques, the project aims to analyze market trends, compare model performance, and identify the most accurate approach for short-term stock price prediction.

## About the Project
This project applies data preprocessing, exploratory data analysis, time series analysis, and predictive modeling to forecast Apple stock prices. Multiple forecasting models, including ARIMA, SARIMA, Random Forest, and XGBoost, were developed and evaluated using performance metrics such as RMSE and MAE. Based on the evaluation, SARIMA was selected as the final model and deployed as an interactive Streamlit web application. The project was developed as part of a **Data Science Internship at AI Variant**.
